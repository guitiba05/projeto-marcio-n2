Avisos

  • nó C: barras AC e CB são colineares (sobrepostas na mesma reta).

Resíduos diferentes de zero na casa de 1e−15 são ruído de ponto flutuante, não erro de formulação. Os valores de esforço normal foram conferidos contra o método dos nós, que é um algoritmo independente do método da rigidez.
